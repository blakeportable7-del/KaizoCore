# Rule changes
## Rule #0 
### The Basics
Journey is based on the original Ironmon ruleset Kaizo difficulty, for everything not mentioned in the changes please refer to those original rules -> https://gist.github.com/valiant-code/adb18d248fa0fae7da6b639e2ee8f9c1
## Rule #1 
### Choose Wisely
You can choose any of the 3 starters, but it will be your only Pokemon. No swapping or pivoting allowed (except for Rule #5)
## Rule #2 
### No Wilds
You cannot intentionally engage in battle with wild Pokémon; always try to run if able (if you get trapped and have Balls, you can catch it to escape, then deposit or release after)
## Rule #3
### Full TM compatibility
100% chance to learn any TM.
## Rule #4 
### Bonus TM
If your starter's held item is a TM, you're allowed to learn it as a "Bonus TM" (for gens without held items on starters, this is replaced by the first obtainable TM outside of Gyms)
## Rule #5 
### Emergency Pivot 
### As soon as your main evolves to its final form, if it gains a banned ability or you are not satisfied with it, you can apply this rule to pivot. 
1. You can catch a wild pokemon from any of the aeras currently open to you, once caught it will replace your main immediately. 
2. You cannot scout their movesets before catching as per rule #2.
3. Unlike classic Ironmon there is no catch limit per route, but you can only catch each pokemon once regardless of the areas. 
4. You can't fight any trainers before pivoting, if you are in the middle of a dungeon you are allowed to leave and return with your new Pokemon. 
5. If your pivot is not fully evolved, you may apply the Emergency Pivot again when it evolves to its final form. 
6. Once you fight a trainer with a main that is fully evolved, you can't apply this rule for the rest of the run.

# Randomizer Settings Changes
### From Original to Journey
- Standardize EXP Curves to: Fluctuating -> Medium Slow
- Ban Negative Abilities: Off -> On
- Limit evolutions to Three stages: Off -> On
- Force Change: On -> Off
- Starter Pokémon: Random (completely) -> Random (basic with 2 evolutions)
- Foe Pokémon - Additional Pokémon for Boss Trainers: 3 -> 1
- Foe Pokémon - Use Similar Strength: Off -> On
- Foe Pokémon - Force Fully Evolved: On -> Off
- Wild Pokémon - Additional Rule: None -> Similar Strength
- Wild Pokémon - Minimum Catch Rate: 4 -> 5 (becomes 100% catch rate)
- TM/HM Compability: Random (completely) -> Full Compatibility (becomes 100% learn rate)

## Important to note
### _How the Randomizer handles evolution trees_
The randomizer will first randomize all evolutions with the usual "Same typing, Similar strength" options, all in trees of either 1, 2 or 3 forms since the limit is set to 3. After that the starters will be chosen from all the 3-stage trees and it counts the first stage as a "Basic pokemon" regardless of its place in its original evolution tree. So it is possible to have a choice such as Graveler or Loudred, I even saw a Scyther once. It means that nothing evolves into this pokemon and that it evolves into something that can evolve again, for example the Graveler tree could look like this: Graveler-> Lairon-> Aerodactyl. This rarely happens though, since not only does the tree have to become possible in the randomization, but it also has to be randomly selected as one of the 3 starters. So if you end up with a choice of a stronger pokemon, consider yourself very lucky, but don't go thinking it will be a guaranteed win.
