## Introduction
These are Randomizer Setting files to be used for playing [Ironmon Journey](https://gist.github.com/PappyQC/b9e28068ba4abbbdf191dd33625b737d), a new fun way to play [Ironmon](https://gist.github.com/valiant-code/adb18d248fa0fae7da6b639e2ee8f9c1)!

## How to Use
1. Download the RNQS file for the game you wish to play from the [RNQS Files](#rnqs-files) section below.
2. Move the downloaded file to your Tracker folder.
   1. You can put the file with the other RNQS files: `~/ironmon_tracker/RandomizerSettings/`
   2. Or you can create a new folder "Journey RNQS Files" in your Tracker folder.
4. Open your emulator, a Pokémon game ROM, and the Ironmon Tracker.
5. Click **Tracker Settings** -> **New Runs** -> **Profiles** -> **Add New**. Then create a new profile to genereate ROMs.
6. [New Run Profile](https://github.com/besteon/Ironmon-Tracker/wiki/New-Runs-Setup) setup:
   1. For Mode, choose "Generate new ROMs"
   2. Select your Pokémon game ROM
   3. Select the Ironmon Randomizer "PokeRandoZX.jar"
   4. Select the Ironmon Journey RNQS file you downloaded
7. Done! You're now ready to [create](https://github.com/besteon/Ironmon-Tracker/wiki/New-Runs-Setup#introduction-to-new-runs) randomized Ironmon Journey ROMs and start playing!
