# Saves, backups and updates

## Auto-save, and coming back

- The auto-save is written every 3 minutes of play, at the start of a battle, and whenever you leave the game.
- Leave and come back, and the game opens where you left it: "Back where you left off." **File**, **Restart** starts
  from the title screen instead.
- After a crash, the next launch goes straight back to the game from the auto-save. In a run, the record counts it.

## Backups

**More**, **Backup and info**, **Back up** writes everything to one file: save states and their screenshots, in-game
saves, the auto-save, locks, notes and favorites, the current and previous run, saved attempts, attempt counts,
settings files, keys and layouts, skins, cheats, emulator settings, tracker themes and the background image, run
history and Nuzlocke ledgers.

Never in it: your library games and patches, prepared base games, BIOS and firmware, your RetroAchievements sign-in,
the stream's code, the cloud link, and the current run's randomizer log until that run is over. The current run's
randomized game is in it, so a restored run comes back whole.

**Restore** asks first, then restarts the app.

## Cloud sync

**Start a new sync file**, or **Use my file from another phone**, links a file in your own cloud storage through
Android's file picker. No account and no server of ours. It syncs when you leave a game, if something changed, at most
every 2 minutes. **Sync now**, **Restore from cloud** and **Unlink** are there too.

## Updates

With **Check for a new build once a day** on (it is, by default), the app asks willowcreek.group once a day for one
small file that names the newest build. Nothing about you or your games goes with it. When there is a newer build:
**Update**, **What's new** or **Later** (Later waits three days). Update checks the download's size and SHA-256, then
hands it to Android's installer, and your games, saves and attempts stay. It never pops up over a game.

## Crash reports and bug reports

After a crash, the next launch asks: **Send report**, **Always send** or **Not now**. A report says where the app
failed, with the phone model, the Android and app versions and the game family. Never a ROM, a save or a file name.

**Report a bug**, under More, Backup and info: write what happened, then **Email Blake**, **Share instead** or
**Bug form**.
